In this chapter you will learn how to use loops in UI-BASIC. Loops simply let you repeat a block of code multiple times without writing it over and over again. They are one of the most powerful tools in programming.

Example 1 | FOR/NEXT Loop

  1. Click the button to open this program in a new editor tab.
  2. Then click the Run button or press F9 to run the program.

FORNEXT.BAS

// A FOR/NEXT loop repeats a block of code a set number of times
// The variable i counts from 1 to 5

FOR i = 1 TO 5
    PRINT "Loop number ", i
NEXT i

// Try changing the 5 to a 10 and run it again
// What happens if you change it to 1?

A FOR/NEXT loop is the most common loop in programming. You tell it where to start, where to stop, and it counts for you. The variable i is called the loop counter — it goes up by 1 each time the loop runs.

Example 2 | WHILE/END WHILE Loop

  1. Click the button to open this program in a new editor tab.
  2. Then click the Run button or press F9 to run the program.

WHILELOOP.BAS

// A WHILE loop keeps running as long as a condition is true
// This loop counts down from 5 to 1

count% = 5

WHILE count% > 0
    PRINT "Countdown: ", count%
    count% = count% - 1
END WHILE

PRINT "Blastoff!"

// Try changing the starting number
// What happens if count% starts at 0?

A WHILE loop is useful when you don't know exactly how many times you need to loop — you just want to keep going until a condition eventually becomes false. Be cautious: if the condition never becomes false, the loop runs forever and ever and ever!

Example 3 | Nested Loops

  1. Click the button to open this program in a new editor tab.
  2. Then click the Run button or press F9 to run the program.

NESTED.BAS

// You can put a loop inside another loop
// This is called a nested loop
// The inner loop runs completely for every single step of the outer loop

FOR row = 1 TO 3
    FOR col = 1 TO 3
        PRINT row, " x ", col, " = ", row * col
    NEXT col
NEXT row

// Try changing the 3s to different numbers
// Can you make a multiplication table up to 5 x 5?

Think of Nested Loops somewhat as a bird's nest - the outer loop is the nest, and the inner loop is the eggs inside it. For every one nest, there are several eggs! Thats how they work, the inner loop completes all of its cycles BEFORE the outer loop moves on

Example 4 | Counting with STEP

  1. Click the button to open this program in a new editor tab.
  2. Then click the Run button or press F9 to run the program.

STEP.BAS

// STEP lets you control how much the loop counter changes each time
// Count by 2s
PRINT "Even numbers:"
FOR i = 2 TO 10 STEP 2
    PRINT i
NEXT i

PRINT

// Count backwards
PRINT "Countdown:"
FOR i = 10 TO 1 STEP -1
    PRINT i
NEXT i

PRINT "Go!"

// Try STEP 3 or STEP 5
// Can you print only odd numbers from 1 to 20?

STEP lets you skip numbers or even count backwards. A negative STEP counts down. This is very useful because it gives you much more control over how your loop operates.
