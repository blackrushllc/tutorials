<< Chapter 5 | Variables and Data Types >>

Now that you know how to work with arrays and lists, you might be wondering — where does all that data actually come from? It starts with variables. In this chapter you'll learn how to create and use variables in UI-BASIC, including numbers and text strings.

Example 1 | Numeric Variable

  1. Click the button to open this program in a new editor tab.
  2. Then click the Run button or press F9 to run the program.

NUMVAR.BAS

// A numeric variable stores a number
// Variable names do not use a dollar sign

LET score = 100
LET bonus = 25
LET total = score + bonus

PRINT "Score: "; score
PRINT "Bonus: "; bonus
PRINT "Total: "; total

// Try changing the values of score and bonus and run it again

LET assigns a value to a variable. You can use variables in math expressions just like regular numbers. Notice that numeric variable names have no special symbol.

Example 2 | String Variable

  1. Click the button to open this program in a new editor tab.
  2. Then click the Run button or press F9 to run the program.

STRINGVAR.BAS

// A string variable stores text
// String variable names always end with a dollar sign $

LET name$ = "Justin"
LET greeting$ = "Hello there, "

PRINT greeting$ + name$
PRINT "Welcome to UI-BASIC!"

// Try changing name$ to your own name

String variables always end with a $ (dollar sign). Text values must be wrapped in double quotes. You can join two strings together using the + operator — this is called concatenation.

Example 3 | Mixing Data Types

  1. Click the button to open this program in a new editor tab.
  2. Then click the Run button or press F9 to run the program.

DATATYPES.BAS

// Combining string and numeric variables in output

LET player$ = "Player One"
LET level = 5
LET health = 100
LET weapon$ = "Lightsaber"

PRINT player$
PRINT "Level: "; level
PRINT "Health: "; health
PRINT "Weapon: "; weapon$

// Try adding a new variable for score and printing it

You can use both string and numeric variables in the same program. Use ; (semicolon) to print a label and a number on the same line. Use + to join two string values together.

Great work! In this chapter you learned that variables are the foundation of every program. Numeric variables store numbers, and string variables store text using the dollar sign convention. These building blocks will show up in everything you write from here on out. See you in Chapter 6!
