<< Chapter 6 | Cleaning Data >>

You've learned how to store data in variables and organize it into arrays — but what happens when that data isn't clean? In the real world, it rarely is. In this chapter you'll learn how to inspect and manipulate string data in UI-BASIC using tools like LEN, LEFT$, RIGHT$, and MID$.

Example 1 | Checking String Length

  1. Click the button to open this program in a new editor tab.
  2. Then click the Run button or press F9 to run the program.

DATALENGTH.BAS

// LEN tells you how many characters are in a string
// This is useful for validating data before using it

LET product$ = "Apple Juice"
LET code$ = "AJ"
LET empty$ = ""

PRINT "Product length: "; LEN(product$)
PRINT "Code length: "; LEN(code$)
PRINT "Empty length: "; LEN(empty$)

// A length of 0 means the field is empty — bad data!
// Try adding your own string and checking its length

LEN counts every character in a string including spaces. Checking length is one of the first steps in data cleaning — if a field has 0 characters, it means the data is missing.

Example 2 | Extracting with LEFT$ and RIGHT$

  1. Click the button to open this program in a new editor tab.
  2. Then click the Run button or press F9 to run the program.

LEFTRIGHT.BAS

// LEFT$ pulls characters from the start of a string
// RIGHT$ pulls characters from the end of a string

LET phone$ = "8135550199"

// Extract area code (first 3 digits)
LET areacode$ = LEFT$(phone$, 3)

// Extract last 4 digits
LET lastfour$ = RIGHT$(phone$, 4)

PRINT "Full number: "; phone$
PRINT "Area code: "; areacode$
PRINT "Last four: "; lastfour$

// Try it with a zip code — pull just the first 5 digits

LEFT$ and RIGHT$ let you extract a specific number of characters from either end of a string. This is useful when data is stored in a combined format and you need to break it apart — like separating an area code from a phone number.

Example 3 | Extracting with MID$

  1. Click the button to open this program in a new editor tab.
  2. Then click the Run button or press F9 to run the program.

MIDSTRING.BAS

// MID$ extracts characters from the middle of a string
// MID$(string$, start, length)
// start = which character to begin at
// length = how many characters to grab

LET date$ = "20240615"

// Extract year (starts at 1, length 4)
LET year$ = MID$(date$, 1, 4)

// Extract month (starts at 5, length 2)
LET month$ = MID$(date$, 5, 2)

// Extract day (starts at 7, length 2)
LET day$ = MID$(date$, 7, 2)

PRINT "Full date: "; date$
PRINT "Year: "; year$
PRINT "Month: "; month$
PRINT "Day: "; day$

// Dates stored as one long number is very common in real data!

MID$ is one of the most powerful string tools. It lets you reach into the middle of a string and pull out exactly what you need. Dates and IDs are often stored as one long string — MID$ lets you break them into usable parts.

Example 4 | Putting It All Together

  1. Click the button to open this program in a new editor tab.
  2. Then click the Run button or press F9 to run the program.

CLEANDATA.BAS

// Real data cleaning combines multiple string functions
// Here we have a product entry that needs to be broken apart

LET entry$ = "FL-OJ-32OZ"

// Check the total length first
PRINT "Entry length: "; LEN(entry$)

// Extract state code (first 2 characters)
LET state$ = LEFT$(entry$, 2)

// Extract size (last 4 characters)
LET size$ = RIGHT$(entry$, 4)

// Extract product code (middle, starts at 4, length 2)
LET product$ = MID$(entry$, 4, 2)

PRINT "State: "; state$
PRINT "Product: "; product$
PRINT "Size: "; size$

// This is exactly how CPG data looks in the real world!
// Try making your own product entry and breaking it apart

Combining LEN, LEFT$, RIGHT$, and MID$ gives you full control over string data. In the real world, product codes, dates, phone numbers, and IDs are often stored as a single string — knowing how to break them apart is a core data skill.
