Basic math and operators let your program calculate values, kind of like having a calculator built directly into your code.

Example 1 | Basic Arithmetic

  1. Click the button to open this program in a new editor tab.
  2. Then click the Run button or press F9 to run the program.

ADDSUB.BAS

// Basic math operators: + add, - subtract, * multiply, / divide
// LET assigns the result of a calculation to a variable

LET a = 10
LET b = 3

PRINT "a + b = "
PRINT a + b

PRINT "a - b = "
PRINT a - b

PRINT "a * b = "
PRINT a * b

PRINT "a / b = "
PRINT a / b

// Try changing a and b to see different results

These four operators are the building blocks of every calculation your program will ever make!

Example 2 | Order of Operations

  1. Click the button to open this program in a new editor tab.
  2. Then click the Run button or press F9 to run the program.

ORDEROPS.BAS

// BASIC follows standard order of operations: parentheses first, then * and /, then + and -
// Use parentheses to control the order yourself

LET result1 = 2 + 3 * 4
PRINT "2 + 3 * 4 = "
PRINT result1

LET result2 = (2 + 3) * 4
PRINT "(2 + 3) * 4 = "
PRINT result2

// Notice how parentheses changed the answer from 14 to 20
// When in doubt, use parentheses to make your intent clear

Order of operations decides which part of a calculation happens first, and parentheses let you override it.

Example 3 | MOD and Remainders

  1. Click the button to open this program in a new editor tab.
  2. Then click the Run button or press F9 to run the program.

MODCHECK.BAS

// MOD gives you the remainder after division
// It's useful for checking even/odd numbers, or cycling through a range

LET num = 17

IF num MOD 2 = 0 THEN
    PRINT "Even number"
ELSE
    PRINT "Odd number"
END IF

LET remainder = num MOD 5
PRINT "17 MOD 5 = "
PRINT remainder

// Try changing num to see how the remainder changes

MOD is one of the most useful operators for things like checking even/odd numbers or cycling through a fixed range of values.

Example 4 | Number Guessing Game

  1. Click the button to open this program in a new editor tab.
  2. Then click the Run button or press F9 to run the program.

NUMBERGAME.BAS

// A simple number guessing game using math and comparisons
// The secret number is fixed for now - try changing it to make your own version

LET secretNumber = 42

PRINT "I'm thinking of a number between 1 and 100."
PRINT "Enter your guess:"
INPUT guess

IF guess = secretNumber THEN
    PRINT "You got it! The number was "
    PRINT secretNumber
ELSE IF guess > secretNumber THEN
    LET difference = guess - secretNumber
    PRINT "Too high! You were off by "
    PRINT difference
ELSE
    LET difference = secretNumber - guess
    PRINT "Too low! You were off by "
    PRINT difference
END IF

// Try wrapping this in a loop (from Chapter 3) to let the player guess again

You just built a working number guessing game using nothing but math and IF statements - the same core logic behind way more complex games.
