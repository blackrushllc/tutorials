In this chapter you will learn about arrays in UI-BASIC. An array is a variable that can hold multiple values at once. Instead of creating a separate variable for every single value, you can store them all in one place and access them by number. Think of it like a row of lockers — each locker has a number, and you can put something different in each one.

Example 1 | Your First Array

  1. Click the button to open this program in a new editor tab.
  2. Then click the Run button or press F9 to run the program.

BASICARRAY.BAS

// DIM creates an array and sets its size
// This creates an array called numbers that holds 5 values

DIM numbers(5)

numbers(1) = 10
numbers(2) = 20
numbers(3) = 30
numbers(4) = 40
numbers(5) = 50

PRINT "First value: ", numbers(1)
PRINT "Third value: ", numbers(3)
PRINT "Fifth value: ", numbers(5)

// Try changing the values and running it again
// What happens if you try to access numbers(6)?

DIM stands for "dimension" — it tells UI-BASIC how many slots your array needs. Each slot is accessed by its index number starting at 1. Change the values in the array and see what prints out.

Example 2 | Array of Words

  1. Click the button to open this program in a new editor tab.
  2. Then click the Run button or press F9 to run the program.

STRINGARRAY.BAS

// Arrays can hold text too
// A string array uses the dollar sign just like a regular string variable

DIM fruits$(3)
fruits$(1) = "Apple"
fruits$(2) = "Banana"
fruits$(3) = "Cherry"

FOR i = 1 TO 3
    PRINT fruits$(i)
NEXT i

// Try changing the fruit names to your favorites
// Can you add a 4th fruit? Remember to update DIM fruits$(3) to DIM fruits$(4)

String arrays work exactly like number arrays — just add the dollar sign. Combining arrays with FOR loops is one of the most useful patterns in programming. Instead of writing PRINT for every single item, the loop does it for you automatically.

Example 3 | Adding Up an Array

  1. Click the button to open this program in a new editor tab.
  2. Then click the Run button or press F9 to run the program.

ARRAYLOOP.BAS

// You can use a loop to process every item in an array
// This program adds up all the scores in an array

DIM scores(5)
scores(1) = 85
scores(2) = 92
scores(3) = 78
scores(4) = 95
scores(5) = 88

total% = 0

FOR i = 1 TO 5
    total% = total% + scores(i)
NEXT i

PRINT "Total score: ", total%
PRINT "Average score: ", total% / 5

// Try changing the scores
// Can you find the highest score using IF inside the loop?

This is where arrays get really powerful. Instead of adding up 5 variables by hand, the loop does it automatically. This same pattern works whether you have 5 items or 500 — you just change the loop range.

Example 4 | A Grid of Values

  1. Click the button to open this program in a new editor tab.
  2. Then click the Run button or press F9 to run the program.

GRID.BAS

// A 2D array is like a grid with rows and columns
// Think of it like a spreadsheet

DIM grid(3, 3)

grid(1, 1) = 1
grid(1, 2) = 2
grid(1, 3) = 3
grid(2, 1) = 4
grid(2, 2) = 5
grid(2, 3) = 6
grid(3, 1) = 7
grid(3, 2) = 8
grid(3, 3) = 9

FOR row = 1 TO 3
    FOR col = 1 TO 3
        PRINT grid(row, col), " "
    NEXT col
    PRINT
NEXT row

// Try changing the values in the grid
// Can you make it print the grid in reverse order?

A 2D array adds a second dimension — like a grid or a table. You need two index numbers to access a value: the row and the column. This is the same structure used in spreadsheets, game boards, and data tables.
